This connects to a Google Sheet you own using a small script Google lets you attach to your own spreadsheet (no backend, no OAuth popup needed here). Each month gets its own tab (e.g. "August 2026") with Week 1–4 and the Monthly Summary laid out in the same criteria/sections as the paper form.

Step 1 — one-time setup in Google Sheets
  1. Open (or create) the Google Sheet you want this to write into.
  2. Extensions → Apps Script.
  3. Delete anything in the editor, then paste the code below.
  4. Deploy → New deployment → type "Web app" → Execute as "Me" → Who has access "Anyone" → Deploy.
  5. Copy the Web app URL it gives you and paste it into Step 2 below.
